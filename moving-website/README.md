# Lift & Lane Moving Website Demo

A standalone, responsive landing-page concept inspired by the information architecture of a local moving-company page. It uses original branding and a CSS-built dimensional truck/box illustration rather than copying American Van Lines branding or assets.

## Preview

Open `index.html` in a browser, or publish the `moving-website/` folder through a static hosting service.

## What's included

- Responsive navigation
- CSS 3D-style moving truck and floating box artwork
- Moving services, process, local-area, FAQ, and CTA sections
- Quote form with required-field validation and a local demo confirmation
- Accessible labels, reduced-motion support, and mobile layout

## Before using with real customers

- Replace the fictional Lift & Lane brand and all sample content.
- Add only verified company details, service areas, licensing/insurance details, and genuine testimonials.
- Connect the quote form to a secure backend, CRM, or form provider. The current form does not transmit or store submissions.
- Add a real privacy policy and consent language appropriate to your business.
- Test mobile, keyboard accessibility, performance, and form delivery.

This is a front-end demo, not a clone of American Van Lines and not a production-ready quote system.
